# X Thread: One-Click Memory for Claude Desktop

## Tweet 1 (Hook)
Every conversation with Claude starts from scratch.

You explain your role, your preferences, your project context. Again and again.

We just shipped one-click installers that fix this. Download, double-click, restart Claude. It remembers now.

## Tweet 2 (What it does)
With OMEGA installed, Claude Desktop remembers:

- Your preferences (concise answers, British English, Python examples)
- Decisions across sessions (project names, architecture choices)
- Your working context (projects, team, how you like to work)

All stored locally on your machine. Nothing leaves your computer.

## Tweet 3 (How simple it is)
Setup takes about a minute:

1. Download the .pkg (macOS) or .exe (Windows)
2. Double-click to install
3. Restart Claude Desktop

No terminal. No Python. No config files. No admin password.

The installer bundles everything. You just click.

## Tweet 4 (Who it's for)
This isn't a developer tool. It's for anyone who uses Claude Desktop regularly:

- Researchers tracking sources across sessions
- Writers who want Claude to learn their voice
- Managers tracking decisions and project context
- Anyone tired of repeating themselves

## Tweet 5 (Design principles)
We built it around a few principles:

- No admin access needed (installs in your user directory)
- Safe for existing setups (merges config, never overwrites)
- Clean uninstall (removes software, preserves your memories)
- Private and local (SQLite database on your machine)
