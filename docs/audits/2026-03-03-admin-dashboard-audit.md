## P0 — Broken (12 issues)

### P0-1 [SECURITY] Entities graph no auth guard (Task #13, Priority 10)
- **File**: `website/app/api/admin/entities/graph/route.ts`
- **Issue**: No `getCurrentUser()` auth check. Anonymous users can GET full entity graph.
- **Fix**: Add auth guard matching `/api/admin/entities/route.ts` pattern.

### P0-2 ApprovalsQueue silent failures (Task #14, Priority 9)
- **File**: `website/app/admin/components/jobs/ApprovalsQueue.tsx`
- **Issue**: `submitAction()` silently swallows non-ok responses in catch block. Safety-critical approval gate has no error feedback.
- **Fix**: Add error state to approval dialog. Show error on !res.ok. Don't close dialog on failure.

### P0-3 DELETE /api/schedules only disables (Task #15, Priority 8)
- **Files**: `website/app/api/schedules/route.ts`, `website/app/admin/components/jobs/JobList.tsx`, `website/app/admin/components/jobs/JobDetailPanel.tsx`
- **Issue**: DELETE only sets `enabled:false`. UI optimistically removes row, then refetch brings it back. Dialog text says "will unload and remove the plist" — also wrong.
- **Fix**: Either actually delete the row, or update UI to show disabled state. Fix misleading dialog copy.

### P0-4 ReactFlow SSR guard missing (Task #16, Priority 8)
- **File**: `website/app/admin/coordination/CoordinationTab.tsx`
- **Issue**: `CoordinationFlow.tsx` directly imports `@xyflow/react`. No `ssr: false` dynamic import guard. SSR crash risk.
- **Fix**: Wrap import with `next/dynamic` and `{ ssr: false }`.

### P0-5 Settings is_default dead checkbox (Task #17, Priority 7)
- **Files**: `website/app/admin/components/Settings.tsx`, `website/app/api/admin/projects/registry/route.ts`
- **Issue**: `is_default` hardcoded to `false` at load, never sent in PATCH. Default checkbox is always unchecked and never saves.
- **Fix**: Read from API, send in PATCH, or remove checkbox if DB column doesn't exist.

### P0-6 Dashboard dead code (Task #18, Priority 6)
- **Files**: `website/app/admin/components/dashboard/ProjectGrid.tsx`, `ProjectCard.tsx`, `ProjectCardShared.tsx`, `ProjectFilters.tsx`, `DetailPanel.tsx`, `ProjectExpanded.tsx`, `dashboardUtils.ts`
- **Issue**: Six files never rendered in Dashboard. `buildProjects` never called.
- **Fix**: Delete if superseded by `projects/ProjectsView`, or wire into Dashboard.

### P0-7 project_summaries FK mismatch (Task #19, Priority 7)
- **File**: `website/app/api/admin/project-summary/route.ts`
- **Issue**: API receives display name ("OMEGA") but FK references lowercase ID ("omega"). FK violation silently caught, summaries never cache, re-generated every page load.
- **Fix**: Normalize project name to lowercase ID before upsert.

### P0-8 Proposal empty event_params (Task #20, Priority 7)
- **Files**: `website/app/admin/components/feed/ApprovalCard.tsx`, `website/app/api/admin/orchestrator-feed/[id]/route.ts`
- **Issue**: Approval sends `event_params:{}` when `metadata.event_params` is absent. Creates broken approval records.
- **Fix**: Validate required fields per `item_type` before sending, or reject empty in API.

### P0-9 RhoMetric redundant queries (Task #21, Priority 6)
- **Files**: `website/app/admin/components/insights/RhoMetric.tsx`, `website/app/admin/components/Insights.tsx`
- **Issue**: RhoMetric makes separate GET /api/admin/verification (5 Supabase queries) on every mount. Same data already computed by /api/admin/insights.
- **Fix**: Pass `data.verification` from Insights as prop. Or replace with existing unused `VerificationRate` component.

### P0-10 CampaignEditor data loss (Task #22, Priority 6)
- **Files**: `website/app/admin/components/insights/CampaignEditor.tsx`, `website/app/api/admin/campaigns/route.ts`
- **Issue**: PATCH body omits `content_type_pool`. If backend does full replace, existing config destroyed on save.
- **Fix**: Include `content_type_pool` in PATCH body, or verify backend does partial merge.

### P0-11 Google Drive button shows when not configured (Task #23, Priority 5)
- **Files**: `website/app/admin/components/KnowledgeBase.tsx`, `website/app/admin/hooks/useGoogleDrivePicker.ts`
- **Issue**: "From Google Drive" button always visible. Without env vars, clicking errors with generic message.
- **Fix**: Check env vars at render time, hide button or show "not configured" tooltip.

### P0-12 LLM Usage 403 for non-owners (Task #24, Priority 5)
- **Files**: `website/app/admin/components/LLMUsage.tsx`, `website/app/api/admin/llm-usage/route.ts`, `website/app/admin/components/shell/Sidebar.tsx`
- **Issue**: API returns 403 for contributor role. Tab visible in Sidebar for all roles but immediately errors.
- **Fix**: Hide tab for non-owners in Sidebar, or relax API auth, or show proper permissions message.
