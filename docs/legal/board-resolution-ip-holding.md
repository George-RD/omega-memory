# BOARD RESOLUTION

## Kokyō Keishō Zaidan Stichting

### Resolution No. 2026-001: Acquisition and Licensing of OMEGA Software IP

---

**Date:** _________________, 2026

**Location:** Oldenzaal, The Netherlands

**Present:** ___________________________ (Bestuurder/Board Member)

**Quorum:** Achieved

---

### BACKGROUND

The Board of Kokyō Keishō Zaidan Stichting (KvK 96951559), having considered:

1. That the Stichting's statutory purpose includes "investing in and promoting technology";

2. That the OMEGA software project ("omega-memory"), a persistent memory system for AI coding agents, represents a significant technology contribution to the open source community;

3. That acquiring the copyright in the OMEGA software and stewarding it as an open source project is directly aligned with the Stichting's statutory purpose;

4. That Jason Sosa, the original author of the OMEGA software, has offered to assign the copyright in the Works to the Stichting;

5. That the Apache License, Version 2.0 is a well-established, permissive open source license suitable for the project's goals;

6. That a dual-licensing structure (open source core + commercial extensions) enables sustainable funding for ongoing development while maintaining open source availability;

---

### RESOLVES

#### 1. Acceptance of IP Assignment

The Board hereby resolves to accept the assignment of copyright in the OMEGA software (all source code, documentation, tests, configuration files, and associated materials) from Jason Sosa to the Stichting, pursuant to a Deed of Assignment of Copyright to be executed between the parties.

#### 2. Open Source Licensing

The Board hereby resolves to license the OMEGA open source core under the Apache License, Version 2.0, effective upon receipt of the copyright assignment. This license shall be irrevocable as to works already released under it.

#### 3. Commercial Licensing

The Board hereby authorizes the negotiation and execution of a commercial IP license agreement between the Stichting (as licensor) and Blackbox AI LLC (as licensee) for commercial extensions of the OMEGA software ("omega-pro"), under arm's-length terms including a market-rate royalty.

#### 4. Contributor License Agreement

The Board hereby resolves to adopt the Developer Certificate of Origin (DCO) as the initial contribution mechanism for external contributors. The Board authorizes a future transition to an Apache Individual Contributor License Agreement (ICLA) if and when the project's scale warrants it.

#### 5. Grant Applications

The Board hereby authorizes the submission of grant applications to NLnet (NGI Zero Commons Fund), Sovereign Tech Fund, and similar funding bodies, using the Stichting as the applicant entity.

#### 6. ANBI Status

The Board acknowledges the legal analysis indicating that ANBI status is not advisable at this time due to the Stichting's equity holding in Element1 PTE LTD. The Board defers any ANBI application until the equity structure is reviewed and, if necessary, restructured.

#### 7. Authorization

The Board authorizes any Bestuurder to execute all documents and take all actions necessary to implement these resolutions, including but not limited to:

- Executing the Deed of Assignment of Copyright;
- Publishing the OMEGA source code under the Apache License, Version 2.0;
- Registering the trade name "OMEGA Foundation" at the KvK (if desired);
- Opening discussions with NLnet and other grant bodies; and
- Engaging legal and tax advisors as needed.
